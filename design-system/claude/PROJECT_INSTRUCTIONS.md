# Instrucciones de proyecto para el agente de diseño

Antes de diseñar una pantalla:

1. Indica audiencia, objetivo principal, dato necesario y acción primaria.
2. Selecciona el patrón de producto más cercano.
3. Compón únicamente con componentes documentados; si falta uno, propón su contrato antes de usarlo.
4. Usa tokens semánticos. No introduzcas hex, radios, sombras o espaciados locales.
5. Produce light y dark, y explica cualquier adaptación entre desktop y mobile.
6. Incluye los estados relevantes y verifica contraste, foco, teclado, touch y texto escalado.

Al entregar:

- Lista los componentes utilizados.
- Lista los tokens semánticos principales.
- Señala cualquier nueva necesidad del sistema.
- Distingue dato real, placeholder editorial y supuesto.
- No generes directamente un tema Flutter/React salvo que se solicite una fase tecnológica independiente.

Una pantalla se considera válida cuando puede implementarse en más de una tecnología sin reinterpretar sus decisiones esenciales.
